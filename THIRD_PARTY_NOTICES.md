# Third-party notices

dartr is a Rust port of Dart code. It contains translations of, and data
derived from, the software listed below. Each section gives the origin, what
dartr takes from it, and the full license text. The license of dartr itself is
in `LICENSE`.

The Dart SDK libraries that dartr reads at run time (`dart:core` and the other
`dart:` libraries) are not part of dartr. They come from the Dart or Flutter
SDK that the user has installed.
