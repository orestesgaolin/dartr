dartr

A Rust port of the Dart analyzer (Dart SDK 3.13.3) with analyze, format, fix and language-server.

Install
$ brew install orestesgaolin/tap/dartr

Benchmarks

Measured on a single machine (Apple M5 Pro, 15 cores, 48 GB RAM) against Dart SDK 3.13.3. Files are analyzed in parallel on all cores. Dart caches results on disk (~/.dartServer); dartr has an optional disk cache (--cache / DARTR_CACHE_DIR, off by default).

Parity

dartr analyze reports the same diagnostics as dart analyze (3.13.3) on Flutter (packages/flutter), flutter_tools, analyzer 9.0.0, a 1.56 million line Flutter application (with analyzer plugins) and 671 real packages from the pub cache and the Flutter SDK. dartr format matches dart format on the dart_style tests and 220 pub packages, dartr fix matches dart fix on 65 pub packages with 85 fixable lints enabled, and dartr language-server matches dart language-server on 8,876 sampled requests across 42 pub packages and registers every capability (plus all 59 requests and 22 notifications of --protocol=analyzer).

Correctness is checked with differential tests against the Dart SDK 3.13.3 tools on the SDK test suite and package corpora; see the README.

Differences

  • Memory: similar to Dart's for dartr analyze on packages (lower on Flutter and the full application; 103 to 122 MB on packages with a warm --cache) and about 2 times Dart's for dartr language-server on packages (slightly lower on the full application; see the memory charts).
  • Disk cache: dartr analyze has an optional disk cache (--cache / DARTR_CACHE_DIR, off by default); dartr language-server analyzes from source on every run, so a warm dart language-server can start faster on packages (1.4 s vs 0.9–3.7 s on flutter_tools, 1.9 s vs 1.3–4.2 s on analyzer 9.0.0, 4.2 s vs 2.0–6.1 s on Flutter).
  • Remaining gaps: dartr fix does not include pubspec.yaml missing_dependency fixes yet. flutter analyze and IntelliJ invoke <sdk>/bin/dart language-server directly and have no setting for another binary.
  • Platforms and SDK requirement: macOS arm64 and Linux x86_64 only. Requires a Dart or Flutter SDK (3.13.3) on PATH to read the dart: libraries.

Editor setup

  • VS Code (Dart-Code): set "dart.analyzerPath" to /opt/homebrew/opt/dartr/libexec/dartr_shim.dart (installed by Homebrew), then reload the window.
  • Neovim, Helix, Zed, Emacs, Sublime: run dartr language-server as the Dart language server.
  • Back to the Dart server: remove "dart.analyzerPath" and reload the window.
  • Details: docs/editor-setup.md.
