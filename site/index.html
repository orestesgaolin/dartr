dartr

A Rust port of the Dart analyzer (Dart SDK 3.13.3) with analyze, format, fix and language-server.

Install
$ brew install orestesgaolin/tap/dartr

Parity

dartr analyze reports the same diagnostics as dart analyze (3.13.3) on Flutter (packages/flutter), flutter_tools, analyzer 9.0.0, a 1.56 million line Flutter application (with analyzer plugins) and 671 real packages from the pub cache and the Flutter SDK. dartr format matches dart format on the dart_style tests and corpora, and dartr language-server registers every capability of dart language-server (plus all 59 requests and 22 notifications of --protocol=analyzer).

Correctness is checked with differential tests against the Dart SDK 3.13.3 tools on the SDK test suite and package corpora; see the README.

Differences

  • Memory: higher than Dart's on packages (language server RSS: 962 MB vs 546 MB on flutter_tools, 910 MB vs 612 MB on analyzer 9.0.0, 1,652 MB vs 823 MB on Flutter; dartr analyze peak RSS: 0.8 GB on analyzer, 1.6 GB on Flutter, 6.0 GB on the 1.56 million line application).
  • No disk cache: dartr analyzes from source on every run, so a warm dart language-server can start faster on packages (1.6 s vs 1.3–2.2 s on flutter_tools, 4.0 s vs 3.6–4.2 s on Flutter).
  • Remaining gaps: dartr fix does not include pubspec.yaml missing_dependency fixes yet. flutter analyze and IntelliJ invoke <sdk>/bin/dart language-server directly and have no setting for another binary.
  • Platforms and SDK requirement: macOS arm64 and Linux x86_64 only. Requires a Dart or Flutter SDK (3.13.3) on PATH to read the dart: libraries.

Editor setup

In VS Code (Dart-Code), set "dart.analyzerPath" to the dartr_shim.dart installed by Homebrew (/opt/homebrew/opt/dartr/libexec/dartr_shim.dart). Editors that launch a binary directly (Neovim, Helix, Zed, Emacs, Sublime) run dartr language-server. Remove "dart.analyzerPath" and reload the window to switch back to the Dart server. See docs/editor-setup.md.
